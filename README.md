# Matrix-Calculator
Description of Matrix Calculator Program
The Matrix Calculator is a menu-driven C program designed to perform basic mathematical operations on matrices. It allows users to enter the dimensions and elements of matrices and perform four operations: matrix addition, matrix subtraction, matrix multiplication, and matrix transpose.

The program uses two-dimensional arrays to store matrix elements and separate user-defined functions for each operation, making the code modular and easy to understand.

It also validates matrix dimensions before performing operations. For addition and subtraction, both matrices must have the same dimensions, whereas for multiplication, the number of columns in the first matrix must equal the number of rows in the second matrix. The program supports matrices of up to 10 × 10 elements.

A menu-driven interface allows users to select an operation and repeat calculations until they choose the Exit option.

Concepts used:
- Two-dimensional arrays
- User-defined functions
- Loops and conditional statements
- Matrix operations
- Function arguments and pointers
- Input validation
- Menu-driven programming
Objective: To understand the implementation of matrix operations in C using arrays, functions, loops, and conditional statements.
